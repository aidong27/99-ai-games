## Why this repository qualifies

Early-stage but actively maintained public AI coding-agent capability archive. It preserves playable browser games with model provenance, variants, run records, validation scripts, and honest source status, so others can inspect how AI agents improve at small game creation over time.

## How I will use API credits

Use credits to generate new game observations, create controlled variants across models, run maintenance refactors, improve metadata and docs, build validation helpers, and compare outputs without hand-editing AI-generated game code.

## Anything else

The project is intentionally modest: no fake stars, downloads, users, screenshots, or impact claims. The near-term focus is clearer run records, accessibility review, demo monitoring, and one carefully scoped Game 003 benchmark brief.
