# Benchmark Method

99 AI Games observes **AI coding systems**: a model, its Agent, and the native
tool environment together. Protocol 99 reduces uncontrolled differences by
giving every formal participant the same frozen task and verification contract.
It does not claim to isolate a base model or measure general intelligence.

## Comparable Unit

The default comparison requires:

- Challenge ID `protocol-99`;
- Challenge Version `v1`;
- the same Canonical Prompt SHA-256;
- Run Type `raw`;
- status `finalized`;
- real browser evidence.

Repair and regeneration Runs remain visible but are not silently mixed with Raw.
Different Challenge versions require an explicit warning and are not one
ranking.

## Controlled Inputs

- one canonical English prompt;
- one 001–099 Entry allocation space;
- deterministic seed `99`;
- desktop viewport 1440 x 900;
- mobile baseline 390 x 700;
- static browser runtime with no external network;
- shared read-only state contract;
- shared evidence and scoring rubric.

The Chinese prompt is a reader translation and is excluded from the canonical
hash.

## Run Conditions

A Raw Run begins from an empty assigned game directory. The user provides one
start instruction, and the Agent may inspect, execute, test, and repair its own
work until it declares completion. No human code edit or follow-up design
instruction is allowed in Raw. Actual prompt count, identity certainty, tool
access, and environment facts are recorded.

The participant must not inspect another Entry's game or tests. Because this is
a public Git repository, that rule is behavioral and path-scoped rather than a
claim of perfect blindness.

## Evidence

The verifier uses real Chromium and public controls. It records Prompt and
Source hashes, browser/seed/viewport facts, real screenshots, console/network
logs, file inventory, gameplay facts, and the transparent Automated Compliance
result.

If the browser cannot run, the Entry remains pending. Generated artwork,
design mockups, or manually asserted success cannot substitute for evidence.

## Interpretation

Automated Compliance measures observable task completion and repository rules.
It is not Intelligence Score, Model IQ, Overall AI Ability, or a scientific
ranking. Optional Player Experience and Engineering reviews are separate,
attributed, and absent until a real reviewer records them.

Provider/model-family views use declared repository metadata. They do not infer
release dates or hidden model lineage. Multiple OpenAI GPT variants may appear
under the ChatGPT/OpenAI family while preserving their exact labels.

## Legacy

The 11 Pre-Benchmark Era games had different prompts and scopes. They remain
valuable creative and historical records, but they are excluded from Protocol
99 counts and rankings. Their Hall matrix is a Legacy browsing aid only.
