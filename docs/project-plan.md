# Project Plan

The former Hall-based growth plan has been superseded by Protocol 99. It remains
available through repository history; current planning follows these rules:

1. freeze each Challenge version and its Prompt Hash;
2. add real AI coding systems gradually through Agent Autopilot;
3. preserve one immutable Raw Run per Entry;
4. keep Repair Runs separate;
5. publish only real browser-verified evidence;
6. compare only matching Challenge Version, Prompt Hash, and Run Type by default;
7. preserve the 11 old games as the Pre-Benchmark Era;
8. create Protocol 99 v2 only after v1 saturates, never by rewriting v1.

Implementation and release procedures are in
[Agent Autopilot](AGENT-AUTOPILOT.md), [Run Protocol](RUN-PROTOCOL.md), and
[Release](RELEASE.md).
