Use this page when sharing the project on X, Reddit, Discord, Bilibili, Xiaohongshu, V2EX, Juejin, Zhihu, or similar communities.

## One-Line Pitch

99 AI Games is a playable archive observing how AI coding agents make browser games.

## Short English Intro

I'm building 99 AI Games - a public playable archive of browser games made with AI coding agents. Each game is treated as an observation sample with metadata, provenance, and a real playable build.

## Longer English Post Template

I'm building 99 AI Games: a public playable archive for observing how AI coding agents make browser games.

It is not a finished 99-game collection. It is an early archive that starts with real playable observation samples. Each sample has source files, metadata, device-support notes, variants, run records, and provenance.

The point is to preserve how AI agents handle game design, logic, controls, feedback, polish, debugging, and accessibility over time.

Demo: https://aidong27.github.io/99-ai-games/
GitHub: https://github.com/aidong27/99-ai-games

## Longer Chinese Post Template

我在做 99 AI Games：一个可玩的 AI 游戏创作档案馆。

它不是“已经完成 99 个小游戏”的合集，也不是假装成熟的平台。现在它还很早，这正是意义所在：从最早的 playable observation samples 开始，记录 AI 编程智能体做游戏时在设计、逻辑、手感、反馈、调试、打磨和可访问性上的变化。

每个游戏都有真实可玩的页面、metadata、device support、variant 和 run record。后续会继续增加和重做 observation samples，但不会用假截图、假用户量或假热度来包装。

## Posting Guidelines

- Do not claim 99 games are finished.
- Do not claim users, stars, downloads, ratings, or virality unless verified.
- Do not post fake screenshots.
- Prefer showing real launcher or game screenshots.
- Be clear that the archive is early.
- Say "current observations" rather than "completed platform".
- Use the social cards as brand assets, not screenshot evidence.
- Use cover posters as promotional artwork, not gameplay evidence.
