# Data Model

## Sources of Truth

```text
benchmarks/<challenge>/<version>/
entries/<number-provider-model-agent>/
  entry.json
  README.md
  runs/<run-id>/
    run.json
    prompt-snapshot.md
    game/
    tests/
    evidence/
```

Challenge files, local `entry.json`, local `run.json`, source, participant
tests, and real evidence are primary records.

## Records

**Challenge** defines prompt, runtime limits, deterministic seed, comparison
policy, rubric, test contract, and SHA-256 lock.

**Entry** is one numbered AI coding system participation. Numbers are 001–099
and allocated by script. Identity stores provider, model and Agent labels,
source, and confidence. Unknown facts are explicit.

**Run** is one implementation attempt with a unique ID, type, status, prompt
hash, timestamps, baseline commit, human input/edit declarations, environment,
parent relationship, known issues, and Finalized integrity hashes.

**Evidence** contains `report.json`, file inventory, console/network logs, and
real screenshots generated by verification.

## Generated Views

`scripts/generate-benchmark.mjs` scans local records and produces:

- `entries/manifest.json`;
- `data/benchmark.json`;
- `docs/generated-benchmark-index.md`;
- Finalized Entry detail redirects;
- real-screenshot-based Entry social cards.

Legacy data remains separately sourced from `games/manifest.json` and
`games/<slug>/game.json`. Never merge Legacy counts into benchmark Entry
counts.

## Production Boundary

`scripts/prepare-pages.mjs` exposes only Finalized Entry metadata, game runtime,
and evidence. Participant tests, prompt snapshots, Work Orders, `.agent/`,
scripts, workflows, and development docs are excluded from
`.site/`. The JSON schemas are public because Challenge, Entry, Run, and
verification records link to them directly.
