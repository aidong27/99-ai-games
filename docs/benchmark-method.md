# Benchmark Method

Benchmarks in this project are qualitative and transparent. They are not scientific claims unless a future process defines strict controls.

## Benchmark Slot

A benchmark observation sample should be useful for comparing AI agents because it has:

- clear rules
- visible controls
- measurable playability
- enough complexity to reveal design tradeoffs
- a small enough scope to inspect

Observation 001 / Game 001, Signal Cartographer, is currently marked as a benchmark slot because it tests canvas rendering, movement, hazard design, resource use, mobile controls, and metadata discipline.

## What To Record

For each benchmark run, record:

- model and agent
- prompt summary
- source output
- verification checks
- known bugs
- what the model did well
- what needed revision

## What Not To Claim

Do not claim a winner, score, or ranking unless the project has actually run a defined comparison method.
