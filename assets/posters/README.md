# Game Cover Posters

`games/<slug>.jpg` contains the vertical promotional cover for each published observation.

These files are editorial artwork. They are not screenshots, gameplay evidence, additional games, or proof of features beyond the metadata and verified build. Generated promo pages display the poster in the hero and keep real repository screenshots in a separate Evidence section.

Current poster contract:

- JPEG, 1024 x 1536 pixels (2:3)
- exact game title and observation number
- `99 AI Games` archive label
- one file for every entry in `games/manifest.json`
- no placement inside `games/<slug>/`, so launcher artwork remains separate from protected game implementations
