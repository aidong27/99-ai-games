# Game Halls

The 99 AI Games archive is organized into 9 halls. Each hall can eventually contain 11 official game concepts, for a total of 99 game slots.

Game numbers are global collection slots. Hall order does not force numeric ranges. For example, Game 001 belongs to the Survival Strategy Hall because that is the best fit for Signal Cartographer.

## Slot Mix

Each hall should eventually include:

- 3 benchmark game concepts
- 6 normal collection game concepts
- 1 failed/weird experiment concept
- 1 future remake concept

Across 9 halls, that creates:

- 27 benchmark concepts
- 54 normal collection concepts
- 9 failed/weird concepts
- 9 future remake concepts
- 99 total game concepts
