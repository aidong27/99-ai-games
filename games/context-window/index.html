    Controls

    • WASD / Arrow keys — move
    • P / Esc — pause, R — restart, M — mute
    • Touch devices get an on-screen direction pad.

    The mechanic is the meme

    • Your context window holds 4 sectors. Entering a 5th evicts the oldest one.
    • Evicted sectors are re-summarized on return: shard positions drift, walls are misremembered, decoys appear.
    • Pink shards are hallucinations. So are the glitch drones. Forgetting breeds more of them.
    • You remember shard counts, never shard locations. Working memory holds 3 shards.

    Pickups

    • System Prompt (pin) — the sector is never evicted.
    • Compression pass — +1 context capacity.
    • Integrity patch — +1 integrity.
