# Lumen Lattice: Prism Archive

**Observation 002 / Game 002 — Puzzle Logic Hall**

A PC-first constraint logic puzzle. Each press sends light through a fixed pattern that
flips a set of prisms. Align every prism to synchronize the lattice.

## Play locally

From the repository root:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173/games/lumen-lattice/>.

## Rules

Each prism is aligned or dark. A press applies the level's active rule:

- **Pulse** — flips the pressed prism and its four orthogonal neighbours.
- **Beam** — flips every prism in the pressed prism's row and column.
- **Split** — flips the pressed prism and its four diagonal neighbours.

The lattice is solved when every prism is aligned. Rules are introduced one at a time, each
with a short note the first time it appears.

## Controls

- **Press prism:** click or tap
- **Move cursor:** WASD or Arrow keys
- **Activate cursor prism:** Space or Enter
- **Hint:** H &middot; **Undo:** U &middot; **Reset:** R &middot; **Pause / menu:** P

## Solvability

Every lattice is generated by reverse-scrambling a fully aligned board, so each puzzle is
guaranteed solvable. The hint tracks the scramble parity and always reveals one prism from a
valid remaining solution (it never solves for you). The QA hook
`window.__lumenLatticeQA.autoSolve()` will finish any board, which makes the solvability
claim directly inspectable.

## QA hooks

```js
window.__lumenLatticeQA = {
  start(), startLevel(index), restart(), reset(), undo(), hint(),
  clickCell(row, col), autoSolve(), isSolved(), getSnapshot()
};
```

`getSnapshot()` returns `mode`, `level`, `size`, `rule`, `moves`, `par`, `aligned`/`total`,
`progress`, `solved`, `remainingMoves`, `cursor`, `hint`, and `won`.
