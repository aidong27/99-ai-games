# Lumen Lattice

**Observation 002 / Game 002 — Puzzle Logic Hall**

A constraint logic puzzle. Pressing a node fires light down its entire row and column,
flipping every lumen the beams cross. Light the whole lattice to synchronize it.

## Play locally

From the repository root:

```bash
python3 -m http.server 4173
```

Then open <http://localhost:4173/games/lumen-lattice/>.

## Rules

- Each node is lit or dark.
- Pressing a node flips every node in its row and its column (the pressed node flips
  once, together with the cross).
- The lattice is solved when every node is lit.

## Controls

- **Press a node:** click or tap
- **Move cursor:** WASD or Arrow keys
- **Fire node:** Space or Enter
- **Hint:** H &middot; **Undo:** U &middot; **Reset:** R

## Solvability

Every lattice is generated by scrambling a fully lit board with random cross-toggle
clicks, so each puzzle is guaranteed solvable. The hint system tracks the parity of the
scramble and always reveals a node from a valid remaining solution. The QA hook
`window.__lumenLatticeQA.autoSolve()` will finish any board, which makes the
solvability claim directly inspectable.
