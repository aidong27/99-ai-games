# Observation 008 Brief: Orbit Cadence

## Purpose

Create a PC-first rhythm-audio benchmark for the Rhythm Audio Hall. The observation focuses on timing windows, pattern memory, audio feedback, input precision, readable judgment, and short-loop clarity under rising density.

## Core Loop

1. Start a ~90-second orbital cadence run.
2. Notes travel along four lanes toward a hit ring.
3. Press lane keys (or tap lane pads) inside the timing window.
4. Build combo and accuracy; hear synthesized hit and miss feedback.
5. Survive rising pattern density until extraction (track end).
6. Fail if integrity reaches zero from repeated misses.

## Design Constraints

- Keep the experience short, readable, and replayable.
- Use a PC-first 16:9 playfield with keyboard-primary timing.
- Prefer clear approach motion and explicit judgment text over surprise failure.
- Use Web Audio API for metronome and judgment tones (no external audio assets required).
- Keep mobile honest as a baseline viewport check with large lane pads, not the intended high-skill mode.
- Do not claim fake screenshots or physical handset QA.
