# Memory Bloom

Observation 006 / Game 006 in 99 AI Games.

A PC-first clicker management game about nurturing a digital memory core. Click to spark data fragments, place collectors, purchase upgrades, and cultivate recursive abundance.

## Play

Open `index.html` in a local static server.

## Controls

- Click the core to spark data fragments
- Click empty space to place collectors (after purchasing)
- Use the upgrade panel to purchase improvements
- P: pause, R: restart
