Lumen Lattice

Lumen Lattice: Prism Archive is a PC-first constraint logic puzzle. Each press sends light through a fixed pattern (pulse, beam, or split) that flips a set of prisms. Every lattice is generated by reverse-scrambling a solved board, so each puzzle is guaranteed solvable, with tracked-parity hint and autoSolve.
