Experiment protocol

Built by agents, maintained with receipts

  1. Game slots represent official concepts, not AI generations.
  2. Model variants live under the same game slot and do not consume new numbers.
  3. Run records preserve generation, revision, validation, and comparison attempts.
  4. The maintainer tests and publishes, but does not hand-write game code.
