Experiment protocol

Built by agents, maintained with receipts

  1. Every game lives in its own folder with a local playable build.
  2. Every game has metadata for model label, agent, date, and edit policy.
  3. The maintainer tests and publishes, but does not hand-write game code.
  4. The project grows gradually so each entry can reflect AI progress at that time.
