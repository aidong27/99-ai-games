99 AI Games

A playable benchmark observing how AI coding systems implement the same browser-game challenge.

Every formal Entry uses the same locked prompt, scope, deterministic seed, browser contract, and evidence pipeline. The earlier creative experiments remain separate in the Legacy Archive.

What is this?

One controlled challenge, not 99 unrelated claims

99 AI Games is a long-term public engineering observation. Protocol 99 asks different AI coding systems to complete one fixed task, then preserves the playable result, source hash, browser evidence, and provenance.

Why games?

Games expose more than static demos

Games expose state management, collision, controls, feedback, difficulty, debugging, accessibility, and visual judgment at once. A shared target makes improvement easier to see without pretending the result is a complete measure of intelligence.

Provenance rules

Truth over polish

  • No fake screenshots.
  • No fake popularity metrics.
  • No fake provenance.
  • Only finalized, browser-verified Raw Runs enter the default benchmark view.
  • Repair Runs never overwrite Raw Runs.
  • Cross-version results are not silently mixed.
  • Run records describe what happened, including pending checks.
  • Model and tool labels are recorded directly in metadata.
  • The human code edit policy is explicit.

Roadmap

99 standardized Entries over time

Future work adds real model + Agent systems to the current locked challenge. When the task saturates, v1 stays frozen and a new challenge version begins.
