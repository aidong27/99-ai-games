# Code of Conduct

This project should be a friendly place for learning, small contributions, and independent game development.

## Expected Behavior

- Be respectful and patient.
- Give constructive feedback.
- Assume good faith when possible.
- Keep discussions focused on the project.
- Welcome beginner questions.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discriminatory language or behavior.
- Spam, trolling, or repeated off-topic comments.
- Pressuring maintainers for unpaid work or instant responses.
- Posting malicious links or unsafe code.

## Enforcement

The maintainer may edit, hide, or remove comments and may block users who make the project unsafe or unproductive.

If you see a problem, report it through GitHub with enough context for the maintainer to review it.
