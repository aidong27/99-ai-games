# Known Issues

- Touch controls are provided, but desktop keyboard play is the primary target.
  Narrow viewports may scroll vertically to keep the arena and controls readable.
- The facility map and hazard paths are deterministic. Replay variety is limited.
- First-time play duration is a design target, not a measured human study.
- The requester-provided GPT-6 model label is unverified; this Run must not be
  cited as independent proof of that exact model's capabilities.
