# New Game Prompt Template

Use this when creating a new official game slot.

```text
Create Game 000 for 99 AI Games.

Game title:
Hall:
Slot type:
Core mechanic:
Target controls:
Visual style:
Accessibility constraints:

Rules:
- Preserve the 99 game slots as concepts, not AI generations.
```
